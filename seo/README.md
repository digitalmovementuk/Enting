# Enting SEO Workspace

All SEO artefacts for this project live under this folder.

## Folder map

- `01_strategy/`
  Source material, architecture notes, briefs and inputs from the SEO page builder workflow.
- `02_research/`
  Keyword exports, competitor research, entity notes and supporting analysis.
- `03_templates/`
  Master page templates, schema fragments and prompt assets.
- `04_build-queue/`
  CSV queues that define which pages should be generated.
- `05_generated/`
  Generated SEO outputs, split into master pages, geo pages and WordPress-ready exports.
- `06_assets/`
  Images, OG assets and other media used by SEO pages.
- `07_deployment/`
  WordPress deployment notes, internal linking plans and HTML sitemap artefacts.
- `08_qa/`
  Launch checklists and validation outputs.
- `09_tracking/`
  Tracking exports and setup artefacts for GSC, GA4, Semrush and AI search monitoring.

## Working rule

If a future task is described as a new page, a new SEO project, or an SEO page builder artefact, it should be stored somewhere inside this `seo/` tree unless there is a stronger project-specific reason not to.
