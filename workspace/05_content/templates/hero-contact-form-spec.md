# Hero Contact Form Spec

## Purpose

Capture high-intent visitors immediately above the fold.

## Placement

- Right side of the hero on desktop
- Below the opening copy on mobile

## Fields

- Name
- Work email
- Company
- Brief message

## Optional hidden fields

- Page slug
- Service cluster
- Primary keyword

## CTA labels

- Book a consultation
- Request a callback
- Talk to Financeable Consulting

## UX notes

- Keep the form visually compact
- Avoid long qualification flows in the hero
- Make completion possible in under 60 seconds
