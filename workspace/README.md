# Financeable Consulting Workspace

This folder holds the SEO, strategy, research, and content artefacts for the Financeable Consulting website that is being built inside the `Enting` repository.

## Current focus

- `02_research/enting-search-term-page-matrix-overview.csv`
  Full 450-page search term and location matrix for the long-range SEO expansion plan.
- `02_research/financeable-consulting-research-summary.md`
  Public-footprint audit, competitor scan, trust-signal check, and safe assumptions for the live site.
- `03_strategy/site-architecture.md`
  Core site information architecture for the public six-page website plus the phased landing-page expansion plan.
- `03_strategy/live-site-sitemap.md`
  Publishable page scope for the live site: homepage, three service pages, about, and contact.
- `04_build_queue/live-site-pages.csv`
  SEO page map for the live site pages that will actually ship.
- `04_build_queue/p1-launch-queue.csv`
  Long-range landing-page queue for the later 450-page buildout.
- `05_content/briefs/`
  Source briefs for homepage, about, contact, and the three core service clusters.
- `05_content/drafts/`
  Long-form source drafts used to shape the published pages.

## Working rule

The live website should pull from the Financeable Consulting artefacts in this workspace. The 450-page expansion plan remains a future rollout stream and is not the public launch scope.
